问答列表

装这个 Verdaccio Mate 会影响正在运行的原版 Verdaccio 吗？

不会。不改配置、不接管端口、也不要求重启，只共享同一份存储目录。扫描是纯读取；只有清理低版本才删除 .tgz 并回写元数据，且由你在 Verdaccio Mate 里确认后才发生。

缓存目录只读挂载能用吗？

查看与扫描可以，清理不行——删除低版本要移除 .tgz 并回写包元数据，只读挂载会报 EROFS。实际部署常用 user: "0:0" 以 root 运行，原因见技术文档 · 部署与配置。

概览页的占用为什么比 du -sh 小？

口径不同。统计卡与排行的体积是包内 .tgz 归档合计，不含 package.json 等文件；真实磁盘占用看 diskMb / diskBytes。

纯内网、不能出公网的环境能用吗？

治理部分完全可用：扫描、来源识别、预警、清理、检索、日志都不依赖外网。npm Top1000 周榜与批量拉取需要相应出网能力，纯内网下对应页面保持空态即可。

不配置 VERDACCIO_STORAGE 会怎样？

后端进入演示模式：使用内置演示数据并禁止拉取，界面数据带 demo 标记，方便先看形态再接真目录。

MCP Key 泄露了怎么办？

在 Verdaccio Mate 的「MCP 接入」里立即吊销，下一次请求即失效；一期开放的全部是只读查询工具，不涉及删除与改用户。

要备份什么？升级会不会丢数据？

备份 DATA_DIR 整个目录（含 SQLite 与 MCP Key 主密钥）。镜像无状态，换 tag 重启即可升级；回滚时保留数据目录再换旧镜像。
