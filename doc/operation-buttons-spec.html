操作栏按钮设计规范 Operation Bar Buttons · Verdaccio Mate

基线：检索页「清理 / 忽略」按钮。全站表格操作栏统一走全局 .btn 体系（frontend/src/styles/base.css），禁止 scoped 内自定义（el-table 单元格不携带 data-v）。

13.1 通用形态 · 规格速览
4px 小圆角 · 紧凑尺寸 · 语义变体背景 · 每行最多 2 个
圆角 4px小圆角（--r-md），全站控件统一，禁用胶囊/直角混用
尺寸 7px 15px常规档 padding 7px 15px · font-size 12.5px；操作列 .op-btn-cell 为 5px 12px / 12px
间距 7px相邻按钮 margin-left 7px，横排一行不换行
背景 语义变体主操作石墨实心、次操作白底描边、危险软底，禁止随意混用
数量 ≤ 2每行至多 2 个，超过收进「更多」菜单
落地 全局声明样式放 base.css，避免 scoped 在 el-table 内失效（84070c0）
13.2 语义色阶 · 5 种变体
默认 / hover / disabled 三态（hover 仅变色，无上浮、无缩放）
主操作 · clean
.btn.clean
默认 hover disabled
次操作 · ignore
.btn.ignore
默认 hover disabled
中性 · unignore
.btn.unignore
默认 hover disabled
危险 · remove
.btn.remove
默认 hover disabled
幽灵 · ghost
.btn.ghost（仅对话框）
默认 hover disabled

13.5 禁忌 · 禁止出现在操作栏
保持视觉一致：4px 圆角 + 语义变体背景是操作栏唯一合法形态
✕ 直角 / 大圆角按钮
圆角 10px+ 或直角，与全局 4px 控件冲突
✕ 描边纯文字（表格内）
表格操作栏禁用描边式；描边仅供对话框 .ghost
✕ 每行超过 2 个 / scoped 自定义
3 个拥挤；组件内 scoped 写样式在 el-table 中失效
