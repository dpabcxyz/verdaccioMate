表格顶部工具栏按钮设计规范 Icon Toolbar Buttons · 无背景色

基线问题：表格顶部右上角「抓榜 / 拉取 / 新增用户」按钮与左下角筛选 tabs 高度不一、文字按钮与图标按钮混用、彩色背景参差。统一走全局 .tool-btn：图标 + tooltip + 无彩色背景，全部同构为「卡片底 + 细边框」，30×30 / 圆角 4px（与筛选 tabs 同高），图标使用 @element-plus/icons-vue。

15.1 通用形态 · 规格速览
4px 小圆角 · 30×30 · 无背景色 · icons-vue 图标 · 悬停出 tooltip
尺寸 30×30px与左下角筛选 tabs 完全同高，两侧齐平
圆角 4px小圆角（--r-md），与全站控件一致
底色 无背景色卡片底 + 1px 细边框，唯一形态，不设彩色背景变体
图标 icons-vue 15px纯图标无文字；由内部 span.ico 承载，便于仅图标旋转
间距 gap 10px相邻按钮等距，工具栏右对齐
落地 全局声明base.css 声明，禁止组件 scoped 自写（防失效）
15.2 统一形态 · 图标即语义（无背景色）
功能语义由图标承担，主次只靠图标含义与排列次序，不再用背景色区分。示例图标为 Element Plus Refresh / Download / Plus。
